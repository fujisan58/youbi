# youbi

![test](https://github.com/fujisan58/youbi/actions/workflows/test.yml/badge.svg)

入力された日の曜日を求めるためのコマンドです。

## インストール

```
$ git clone https://github.com/fujisan58/youbi.git
$ cd youbi
$ chmod +x youbi
```

## 使い方

調べたい日付をコマンドの引数として指定します。`./youbi 年-月-日` を入力してください。入力した日付と、その曜日が表示されます。

```
$ ./youbi 2005-04-01
2005-04-01 金曜日
```

調べたい日付が複数あるときは、1行に日付を1つずつ書いて、パイプ（`|`）で渡してください。

```
$ printf "2005-04-01\n1989-01-07\n" | ./youbi
2005-04-01 金曜日
1989-01-07 土曜日
```

日付の形式が間違っている場合や、存在しない日付を入力した場合は、標準エラー出力に「日付の形が違う」と表示されます。間違った日付は処理されません、残りの正しい日付は処理されます。また、1つでも間違った日付があった場合は、終了ステータスが `1` になります。
